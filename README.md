# Braun — интерактивный плакат

Учебный стенд с векторными буквами и пятью независимыми вертикальными осями.

## Открыть

Откройте `index.html` в браузере. Установка зависимостей и сборка не нужны.
Файлы `panel.css`, `panel.js` и папку `panel-lib` оставьте рядом с ним.

## Управление

- Кнопка настроек в нижнем левом углу открывает панель.
- «Включить движение / Выключить движение» управляет автоматическим ходом.
  В сохранённом эталоне движение включено, скорости осей — 26, 72, 126, 164 и 200.
  При открытии применяются настройки, сохранённые в этом браузере, или эталон из файла.
- «Сбросить вид» возвращает исходные положения и пропорции букв и выключает движение.
- «Разделить скорости / Включить одну скорость» выбирает отдельные скорости осей или общую.
- Оси можно прокручивать мышью или пальцем, перетаскивая их по вертикали.
- Наведение меняет ритм выбранной оси между тремя и четырьмя буквами.
- Маленькие подписи становятся белыми в местах пересечения с буквами.
- «Общий поток» задаёт одну кривую для всех пяти осей. Кривую ведите
  сверху вниз, без петель: её боковой изгиб действует на всю ширину плаката.
- «Сила» регулирует размах изгиба, «Пластичность» — от сдвига буквы
  целиком до изгиба её векторного контура. Кривую можно править в панели
  или кнопкой «править на макете».
- «Сбросить вид» также выпрямляет общую кривую.
- Настройки панели сохраняются в браузере; сброс вида сохраняет значения скоростей.
- «Сбросить настройки» возвращает сохранённый эталон, включая общую кривую.
