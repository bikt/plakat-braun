# Braun — интерактивный плакат

Учебный стенд с векторными буквами и пятью независимыми вертикальными осями.

## Открыть

Откройте `index.html` в браузере. Установка зависимостей и сборка не нужны.
Файлы `panel.css`, `panel.js` и папку `panel-lib` оставьте рядом с ним.

## Управление

- Кнопка настроек в нижнем левом углу открывает панель.
- При каждом открытии плакат прямой, автоматическое движение выключено.
- «Включить инверсию / Вернуть исходные цвета» переключает тему плаката.
  В инверсии фон тёмный, буквы оранжевые.
- Буквы повторяются до краёв окна с сохранением пропорций. Одинаковые
  колонки во всех повторах двигаются вместе.
- «Включить искажённый вид» восстанавливает сохранённую кривую и все пять
  скоростей, не запуская движение. «Вернуть обычный вид»
  выпрямляет поток, возвращает исходные положения и пропорции
  букв и выключает движение.
- «Включить движение / Выключить движение» управляет автоматическим ходом.
  Движение можно включить в любом виде. Скорости по умолчанию — 26, 72, 126, 164 и 200.
- «Разделить скорости / Включить одну скорость» выбирает отдельные скорости осей или общую.
- При открытии ритм `4 4 3 4 4`. Прокрутка вниз проходит выбранный сценарий
  и начинает круг заново. Вверх круг идёт в обратном порядке.
  Один щелчок колеса, вертикальный свайп или нажатие стрелки на плакате
  выбирает соседний ритм. Следующий жест сразу задаёт новый переход.
- В «Перемене ритма» список «Сценарий прокрутки» предлагает исходный порядок,
  «Перекат», «Вдох», «Маятник» и «Свой». В «Своём» выберите шаг и задайте
  по 3 или 4 буквы на каждой оси. Можно добавлять, удалять и переставлять шаги.
  Выбор и правка шага показывают его на плакате. Стартовый ритм стоит перед
  первым шагом каждого сценария.
- Наведение сразу работает вместе с прокруткой. Каждая буква выбирает для всех
  колонок свой ритм из таблицы. Прокрутка меняет выбранный шаг, даже если
  курсор остался на букве. Движение курсора снова выбирает
  ритм наведением. При уходе курсора с плаката возвращается ритм прокрутки.
- В разделе «Перемена ритма» можно выключить прокрутку или разъединить колонки,
  чтобы при наведении реагировала только выбранная колонка.
- Мышью можно перетаскивать оси по вертикали. На сенсорном экране свайп меняет
  ритм при включённой прокрутке и перетаскивает ось при выключенной.
- Сила регулирует размах смены ритма. Инерция сглаживает наведение.
  При системной настройке уменьшенного движения наведение меняет ритм сразу.
- Маленькие подписи повторяются вместе с блоками BRAUN. Поверх букв они
  становятся белыми в исходной теме и тёмными в инверсии.
- «Общий поток» задаёт одну кривую для всех пяти осей. Кривую ведите
  сверху вниз, без петель: её боковой изгиб действует на всю ширину плаката.
- «Сила» регулирует размах изгиба, «Пластичность» — от сдвига буквы
  целиком до изгиба её векторного контура. Кривую можно править в панели
  или кнопкой «править на макете».
- Браузер запоминает тему, выбранный сценарий и свои шаги. Остальные настройки
  действуют до следующего открытия. Обычный вид сохраняет текущие скорости.
- «Сбросить настройки» возвращает исходные значения, включая прямую траекторию.

| Шаг исходного сценария | Буква под курсором | Ритм B R A U N |
| --- | --- | --- |
| 1 | B | 4 3 4 3 4 |
| 2 | R | 3 4 3 4 3 |
| 3 | A | 4 4 4 4 4 |
| 4 | U | 3 3 3 3 3 |
| 5 | N | 3 4 4 3 3 |

## Источники

Композиция основана на плакате Braun — systems для выставки 2013 года;
дизайн Felix Pfäffli / Studio Feixen. Контуры букв взяты из предоставленного
макета Figma: `c082R8jdTFoigD6nM63tQr`, страница `598:47`.
Исходные SVG лежат в `assets/braun-*.svg`; те же пути встроены в `index.html`
для изгиба букв и маски подписей. Размеры ячеек и ритм стенда сохранены.
